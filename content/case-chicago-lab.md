# BUILT FROM THE GROUND.

From initial sizing and procurement to a working laboratory environment, followed by ongoing call-based support.

## Scope

The initial work covered the full IT environment: endpoints, servers, racks, switching, firewalling, cabling, telephony and laboratory connectivity.

Windows Server 2019, Active Directory, VLANs, PoE and pfSense connect laboratory, accounting and operations workflows.

The scope includes 3CX/Yealink voice, SIP fax, custom print queues, and RS-232 laboratory-device integration.

The arrangement evolved from full-time build work into on-call troubleshooting, patching, upgrades and changes.

The company site uses Drupal/SiteGround. Work with external developers on secure report delivery is a separate responsibility.

## Topics

Infrastructure build, Networking, Identity, Telephony, Laboratory connectivity, Ongoing support
